# 音乐情感表达指南

> 适用对象：进行作曲、编曲、音色设计、音频生成、音乐修改与评价的 AI。
>
> 核心目标：不仅生成“带有某种情绪标签”的音乐，还要让情绪随乐句、段落和声音状态自然变化，形成可信、细腻、有层次的表达。

## 一、基本原则

### 1. 情感不是音色标签，而是时间中的变化

“悲伤的合成器”“温暖的钢琴”只能提供初步色彩。真正的情感表达来自以下层面共同作用：

1. **作曲**：旋律、和声、节奏、结构与留白；
2. **演奏**：力度、时值、连断、呼吸、揉音与起音；
3. **音色**：明暗、粗糙度、噪声、稳定性和频谱演化；
4. **空间与混音**：距离、密度、动态、频率平衡和声部关系。

不要试图用一种音色弥补旋律、和声与演奏中缺失的情绪。

### 2. 不把情绪公式化

“大调等于快乐、小调等于悲伤”“慢等于温柔、快等于激动”都只是特定语境下的倾向，不是规则。调式、速度、音色和和声的意义会受到文化、旋律走向、节奏、歌词、配器及听众经验影响。

应优先建立**一致的音乐语境**，再使用这些倾向，而不是机械套用标签。

### 3. 细腻来自相关变化，而不是随机变化

连续音符应当相似而不完全相同。力度、音长、亮度、揉音和起音变化需要服从乐句方向与演奏状态。不要给每个音符独立添加相同幅度的随机扰动。

优先采用：

- 乐句级渐强、渐弱和呼吸；
- 音符之间的状态继承；
- 力度、音色和发音方式的联动；
- 重复动机出现时的小型变奏；
- 有方向、有限幅的缓慢漂移。

### 4. 对比与克制比持续堆叠更有效

持续的高音区、强力度、宽声场、大混响和高密度，会让情绪迅速饱和。强烈的段落需要相对安静的段落衬托；亲密感也需要与距离感形成对照。

留白不是空白，而是让前一事件产生余韵，让下一事件获得期待。

## 二、建立情绪目标

### 1. 使用四个维度描述情绪

在开始生成前，先确定以下维度。每个维度都可以随时间变化。

| 维度 | 含义 | 常见音乐关联，但不是固定规则 |
|---|---|---|
| **效价** | 明亮、愉悦，或阴暗、痛苦 | 和声稳定度、音区、音色明暗、旋律解决方式 |
| **唤醒度** | 平静、低能量，或活跃、高能量 | 速度、事件密度、节奏清晰度、动态与高频能量 |
| **紧张度** | 松弛、安全，或悬置、压迫 | 不协和、低音持续、未解决和声、频谱粗糙度、密度累积 |
| **距离感** | 亲密、贴近，或宏大、遥远 | 干声比例、演奏噪声、声场宽度、混响、声部数量与音域跨度 |

另可加入“克制—外放”“脆弱—坚定”“私人—公共”等语义轴，但必须转换成具体音乐行为。

### 2. 写情绪弧线，而不只写情绪名称

推荐使用以下句式：

> 从【初始状态】开始，经过【累积或转折】，短暂到达【情绪高点】，最终以【解决、未解决或消退】结束。

示例：

> 从克制、疏离的独白开始，在中段因回忆短暂变得温暖明亮，但没有彻底解决，最后回到安静而略有未竟之感的状态。

情绪转折点应对应可听见的音乐事件，例如和声改变、旋律高点、声部撤离、音色变亮、节奏停止或空间突然收窄。

### 3. 明确视角与场景

同一种“悲伤”可以表现为低声自语、公开宣泄、遥远回忆或压抑愤怒。生成前尽量确定：

- 谁在表达：第一人称独白、旁观者叙述，还是无明确主体；
- 对谁表达：自己、某个具体对象、群体，或没有对象；
- 表达发生在哪里：近距离房间、空旷舞台、自然环境、抽象内心空间；
- 情绪是否被克制：直接宣泄与努力保持平静需要不同写法。

## 三、音乐要素的情感控制

### 1. 旋律：建立语气与呼吸

重点控制：

- **音域**：窄音域常适合克制、私密表达；宽音域可扩大张力，但不应持续高音。
- **方向**：上行可以形成期待或努力，下行可以形成落回与消退，但最终意义取决于和声及节奏。
- **音程**：级进通常更接近连贯叙述；跳进可制造渴望、惊动或强调。大跳之后是否回填，会显著影响情绪。
- **句长**：短句可呈现犹豫、喘息或碎片感；长句可呈现连贯、舒展或难以停止的倾诉。
- **高点位置**：高点过早会削弱后续空间；多次无差别高点会让旋律失去方向。
- **结尾**：解决、停在非稳定音、逐渐消失或突然中断，分别形成不同余韵。

旋律不要只追求“好听”。应检查它是否像一句话：有起始、有强调、有停顿，也有没有说完的部分。

### 2. 和声：管理期待与解决

可使用的手段：

- 延长稳定和弦，营造安全、静止或停滞；
- 降低和声节奏，让旋律细节更突出；
- 使用延伸音、挂留音和经过音，产生温和摩擦；
- 延迟低音移动，使上方声部悬而未决；
- 通过内声部半音或级进连接，形成细腻变化；
- 借用调式色彩或短暂离调，制造情绪转折；
- 在高潮后减少和声数量，而不是继续堆叠。

不要默认复杂和声等于深刻。若旋律、节奏和演奏没有呼吸，再复杂的和弦也可能只是背景装饰。

### 3. 节奏：形成身体感与句法

- 稳定脉冲可带来确定、行进或机械感；
- 模糊脉冲可带来漂浮、梦境或失去支撑的感觉；
- 切分可产生向前牵引，但持续切分会削弱其效果；
- 密度增加可累积能量，密度突然下降可形成暴露感或空白；
- 微时序应成组出现：句首克制、句中推进、句尾放缓，比逐音随机偏移更自然。

若使用 Swing 或 Humanize，必须同时考虑力度、发音和声部关系，而不只是移动音符位置。

### 4. 结构：让重复产生新意义

重复是记忆的基础，变奏是情绪发展的基础。动机再次出现时可以改变：

- 和声背景；
- 音区或音色；
- 最后一个音；
- 声部数量；
- 节奏密度；
- 空间距离。

避免每八小节机械增加一层。也可以在高点后撤掉低频、打击乐或和声层，让主声部暴露出来。

### 5. 力度与发音：决定“人是否在场”

至少设计三个尺度：

- **音符级**：起音、重音、连奏、断奏和释放；
- **乐句级**：渐强、渐弱、呼吸、句尾收束；
- **段落级**：整体能量、动态余量和高潮对比。

力度增加时，真实或可信的音色通常还会变亮、起音更快、噪声或粗糙度增加。不要把力度仅仅映射为音量。

### 6. 音色：让材质回应情绪

| 音色特征 | 可产生的倾向 | 使用注意 |
|---|---|---|
| 柔软起音、少量气流 | 亲密、脆弱、克制 | 气流不能恒定，否则会像持续嘶声 |
| 温暖中低频、柔和高频 | 安慰、怀旧、稳定 | 低频过多会浑浊并削弱清晰度 |
| 明亮泛音、快速响应 | 清晰、外放、能量上升 | 持续明亮容易疲劳 |
| 非谐和、粗糙调制 | 紧张、不安、物质感 | 随机粗糙不等于情绪张力 |
| 轻微漂移、非周期颤动 | 有机、活着、 imperfect | 不应破坏音高与乐句稳定 |
| 清晰瞬态、干净释放 | 决断、秩序、节奏明确 | 过度整齐容易机械 |

优先使用“演奏状态 → 音色响应”的关系，例如乐句越高、力度越强，泛音和气息适度增加；句尾则逐步收拢。

### 7. 空间与混音：控制心理距离

- 亲密段落可保留更多干声、近距离细节和较窄声场；
- 遥远或宏大段落可增加空间尾音、音域跨度和声部宽度；
- 距离增加通常还伴随高频减少和直达声比例降低；
- 混响不能代替声源释放，也不能掩盖起音和发音；
- 保留动态余量，不要用持续限制、压缩和满频谱密度制造虚假的激烈。

## 四、常见情绪的写作方向

以下仅是起点，必须根据语境调整。

| 情绪 | 可尝试的组合 | 常见误区 |
|---|---|---|
| **温柔／亲密** | 窄至中音域、连贯句法、柔软起音、近距离干声、适度留白 | 全部声音都过软，导致轮廓消失 |
| **克制悲伤** | 缓慢和声节奏、内声部移动、句尾不完全解决、有限动态 | 一味慢、小声、小调，缺少变化 |
| **怀念** | 熟悉动机反复出现、每次略变、暖色与轻微老化质感并存 | 把怀旧等同于噪点、磁带抖动和低通 |
| **希望** | 逐步扩展音域、稳定低音、和声逐步打开、句尾获得支撑 | 突然转大调并堆满声部，显得廉价 |
| **孤独** | 主声部暴露、回应声部稀少、空间较大但干声仍可辨 | 只加超长混响，失去主体 |
| **焦虑** | 不稳定周期、重复细胞、低音持续、逐渐缩短句长、有限粗糙度 | 全程高密度和不协和，没有累积过程 |
| **喜悦** | 清晰脉冲、开放音域、旋律推进、明亮但不过载的音色 | 只提高速度和音量 |
| **愤怒** | 明确重音、压缩句长、粗糙激励、节奏对抗、适度不协和 | 持续最大失真，失去动态和攻击性对比 |
| **宏大／崇高** | 宽音域、长呼吸、层次递进、稳定低频与逐步打开的空间 | 从第一秒就满编制、满混响 |

## 五、AI 音色与生成音乐的工作流

### 1. 优先选择能保留表达控制的路线

按细腻表达的可控性，通常可优先考虑：

1. **MIDI／音符与表情控制 → 可演奏神经乐器或合成器**：方便修改旋律、和声和演奏；
2. **哼唱、演奏或已有音频 → 音色迁移**：保留原演奏的呼吸、力度和音高变化；
3. **文本 → 单音、短句或采样**：适合纹理、点缀和声音设计，需要后续剪辑与组织；
4. **文本 → 完整音乐**：适合快速探索方向，但精细修改通常更依赖分轨、局部重生成或后期重编。

具体能力取决于所用系统，不得虚构模型支持的控制接口。

### 2. 推荐流程

1. 写出情绪弧线、视角、场景和结构；
2. 先用简单音色完成旋律、和声、节奏和动态；
3. 检查没有复杂音色时，情绪是否仍然成立；
4. 再生成或迁移主音色，保留多个有细微差异的版本；
5. 按乐句选择版本，而不是无规则随机切换；
6. 添加中景和声与远景环境层，控制密度；
7. 重新调整演奏、空间和自动化，让各层服务同一情绪方向；
8. 导出分轨、MIDI、参数或版本信息，保留修改能力。

### 3. 使用 AI 时的约束

- 不只使用“悲伤、温暖、电影感”等形容词，应补充发声机制、演奏方式和时间变化；
- 不要把多个互相冲突的风格与情绪标签全部堆入提示词；
- 若系统只能生成固定音频，应明确其不可直接修改的部分，通过剪辑、分层和重生成处理；
- 未实际生成、执行或试听时，不得声称已验证音频效果；
- 不伪造 MIDI、分轨、音频文件或模型参数；
- 保留可复现信息，如提示词、随机种子、模型设置和版本，但仅在系统实际支持时提供。

## 六、可复用的生成提示词模板

```text
请创作或设计一段具有细腻情感变化的音乐，并给出可执行的作曲、演奏、音色与空间方案。

【表达目标】
情绪不是单一标签，而是：从［初始状态］，经过［发展／转折］，到达［高点］，最后以［结尾状态］收束。
表达视角：［独白／对话／旁观者／抽象氛围］。
心理距离：［亲密／适中／遥远］。
克制程度：［高度克制／逐渐外放／直接宣泄］。

【音乐设计】
时长与段落：［填写］。
旋律：说明音域、句长、动机、主要高点和结尾解决方式。
和声：说明和声节奏、稳定与悬置的位置、转折和弦或内声部运动。
节奏：说明脉冲清晰度、事件密度、微时序与留白。
演奏：给出音符级、乐句级和段落级力度及发音变化。

【音色与空间】
主音色：说明激励、起音、持续、释放、频谱演化及演奏联动。
辅助层：最多［数量］层，并说明各层职责，避免重复铺底。
空间：分别描述干声、早期反射、距离与尾音。

【交付】
输出结构、旋律／和声说明、演奏自动化、音色参数或提示词，以及验证方法。
若平台支持，提供 MIDI、代码、分轨或可编辑工程；不支持时明确限制，不假装已生成文件。

【避免】
避免机械量化、无方向随机化、持续满密度、全程大混响，以及仅通过小调／慢速／音量表达情绪。
```

## 七、输出与评价格式

当 AI 被要求生成方案、修改作品或分析情感表达时，按以下顺序输出：

1. **情绪理解**：视角、场景、四个情绪维度和时间弧线；
2. **结构时间线**：列出关键段落、转折事件和留白；
3. **作曲设计**：旋律、和声、节奏、动机及其重复方式；
4. **演奏设计**：力度、连断、呼吸、微时序和音色联动；
5. **音色与空间**：主声部、辅助层、距离及动态处理；
6. **实现内容**：按平台提供 MIDI、代码、参数、提示词或编辑步骤；
7. **验证与修正**：指出最可能削弱情感的三处问题，并给出具体修正。

## 八、质量自检清单

### 作曲层面

- 删除复杂音色后，旋律与和声是否仍有情绪方向？
- 是否有明确的动机，而不是持续生成新材料？
- 重复出现时，意义是否发生变化？
- 情绪高点是否唯一或有层级，而不是每段都同样激烈？
- 结尾是否符合预设的解决、未解决或消退状态？

### 演奏层面

- 是否存在乐句级力度、发音和呼吸，而不仅是逐音随机？
- 强力度是否同时改变音色和起音？
- 连奏、断奏和释放是否服务于句法？
- 微时序是否成组、克制且不破坏律动？

### 音色与空间层面

- 主音色是否会随乐句演化？
- 干声关闭混响后是否仍有表达力？
- 辅助层是否具有不同职责，而不是重复填充？
- 是否保留近景细节与足够动态余量？

### AI 交付层面

- 是否明确区分实际生成结果、设计建议和假设？
- 是否保留足够的可编辑性与复现信息？
- 是否避免声称未实际进行的生成、执行或试听？

## 九、简例：克制的怀念

**目标弧线**：安静独白 → 回忆逐渐变暖 → 短暂接近情绪高点 → 主声部孤立 → 未完全解决地结束。

**作曲**：先使用窄音域短动机，第一次结束时停在略带悬置的音上；第二次重复保留旋律轮廓，但通过内声部移动改变和声色彩；中段只扩大少量音域，不突然高音爆发；结尾撤掉辅助层，让动机最后两个音单独出现。

**演奏**：句首轻而略迟，句中逐渐增加连奏与亮度，句尾放松并缩短最后重音；整体保留安静段与高点之间的动态差距。

**音色**：近距离木质或气息主音，起音有少量摩擦；力度增加时泛音适度增多；持续段缓慢变暗；释放保留短余振。辅助层只承担和声与远处环境，不持续铺满高频。

**空间**：开头较干、较近；中段略微打开；结尾不是简单增大混响，而是减少声部，让有限尾音暴露出来。

**检查**：若关闭环境层后情绪完全消失，说明主声部作曲或演奏不足；若每次动机重复都同样明亮、同样大声，应减少参数复位并增加乐句状态差异。

## 十、一句话总结

**先让音符形成有呼吸、有期待、有未竟之意的句子，再让 AI 音色回应这些句子；情感细腻度来自有方向的变化与克制，而不是情绪标签、复杂音色或随机化的堆叠。**
